# Comprar o quê?

Um aplicativo moderno, colaborativo e prático para gerenciar suas listas de compras em tempo real. Com o "Comprar o quê?", você pode criar listas de compras, compartilhar com seus amigos ou familiares através de códigos exclusivos e ver as atualizações em tempo real enquanto todos adicionam ou marcam itens no mercado.

## 💡 A Ideia e Funcionamento
O objetivo principal do app é acabar com o papel e caneta (ou mensagens perdidas no WhatsApp) na hora de fazer compras conjuntas. 
- **Crie listas:** Adicione listas para o mercado, farmácia, etc.
- **Colabore:** Compartilhe o código da sua lista com os moradores da casa. Eles poderão entrar na lista e os itens serão sincronizados para todos.
- **Níveis de Acesso:** Controle quem pode apenas ler, editar ou gerenciar a lista (Admin).
- **Personalização:** Escolha ícones, defina tamanhos.

O aplicativo utiliza **Flutter** para ser multiplataforma (podendo rodar tanto em celulares Android/iOS quanto no computador via Windows e web), e se conecta a um backend (Supabase) para manter tudo sincronizado online.

## 📱 Como Baixar (Android)

Faça o download direto do aplicativo para o seu celular, sem precisar de computador:

1. [⬇️ **Baixar o APK do Comprar o Quê?**](https://github.com/Gustavo-Gomide/ListaCompra/releases/latest/download/app-release.apk)
2. Ao terminar de baixar, clique no arquivo baixado no seu celular.
3. Se o celular pedir permissão para "Instalar de fontes desconhecidas", você pode permitir.
4. Pronto! O app será instalado e já pode ser usado.

---

## 💻 Como Baixar (Windows)

Você pode rodar o aplicativo de forma nativa no seu computador!

1. [⬇️ **Baixar a versão para Windows (.zip)**](https://github.com/Gustavo-Gomide/ListaCompra/releases/latest/download/lista_compras_windows.zip)
2. Após o download, extraia (descompacte) a pasta `.zip` em qualquer lugar do seu computador (como a Área de Trabalho).
3. Abra a pasta extraída e dê um duplo-clique no arquivo executável `lista_compras.exe`.
4. (Opcional) Você pode criar um atalho desse arquivo na sua Área de Trabalho para facilitar o acesso diário.
